# Bhoomi Setu (ಭೂಮಿ ಸೇತು)

### Karnataka Land Acquisition Management & Statutory Revenue Web Platform

An authoritative, production-grade digital platform for the **Government of Karnataka (Revenue Department)** featuring 32 interconnected modules, 3-tier role authentication (Landowner, SLAO Officer, Executive Desk), advanced Leaflet GIS satellite mapping, and an on-screen plain-English guide.

---

## 🚀 Live Demo / Running Locally

### Option 1: Using Node.js
```bash
npm start
```
Then open `http://localhost:3000` in your browser.

### Option 2: Direct File Opening
Double-click `index.html` to open directly in any web browser with zero server installation required.

---

## 🌐 Deploying to GitHub Pages (Free Live Link)

1. Push this repository to GitHub.
2. In your GitHub repository, go to **Settings ➔ Pages**.
3. Under **Branch**, select `main` (or `master`) and `/ (root)` folder.
4. Click **Save**.
5. Your live website link will be ready at:
   `https://<your-username>.github.io/<repo-name>/`

## 👥 3 Core User Roles & Workflows

1. **👨‍🌾 Landowner / Citizen (Rajesh Kumar)**:
   - View registered land parcels (Survey 48/2A Bellandur).
   - Verify ₹6.78 Crore statutory compensation breakdown.
   - Inspect plot boundaries on high-resolution satellite GIS maps.
   - File Section 15(1) valuation objections.

2. **👔 Special Land Acquisition Officer (Sri. B. Shivaram, KAS)**:
   - Verify citizen property deeds and title records in split-view console.
   - Apply cryptographic Class-3 DSC digital green stamps.
   - Forward files through the 4-tier statutory approval pipeline.
   - Publish official Karnataka State Gazette declarations.

3. **🏢 State Executive Command (Chief Secretary)**:
   - Track statewide infrastructure corridors (Namma Metro Phase 2A, PRR).
   - Evaluate ML delay predictions (+4.2 months).
   - Run AI turnaround simulations saving 117 days and ₹84 Crores in public expenditure.

## 🛠️ Technology Stack
- **Frontend**: Vanilla JavaScript (ES6+), HTML5, Tailwind CSS tokens (`civic_authority`).
- **Mapping**: Leaflet.js with CartoDB Positron and ESRI World Imagery Satellite tiles.
- **Routing**: Client-Side Hash Router (`#/`).
- **Server**: Lightweight zero-dependency Node.js HTTP server.
